Esta chave será criptografada neste navegador para reduzir a exposição acidental. Como o site funciona sem servidor, isso não oferece a mesma proteção de um backend.

Para corrigir uma resposta, serão enviados ao Google Gemini a pergunta, sua resposta, a resolução sugerida e as regras de pontuação. Não serão enviados seu nome, histórico completo, chave de API nem outros dados do site. No nível gratuito, o Google pode usar os dados processados para melhorar seus produtos.
